# Archived Benchmark Version 1

Version 1 was frozen before the first retrieval run. A subsequent coverage audit found that 68 of its 74 required evidence groups targeted textbook-reference files, leaving too few syllabus and course-context anchors for a balanced source-role assessment. The complete dataset, manifest, reports, scored results, and raw run outputs are preserved here.

Version 2 changes questions and anchors to cover 46 textbook-reference, 16 context, and 13 syllabus groups; its metrics are not directly comparable to version 1 because the dataset changed. No retrieval model or ranking parameters were tuned between the version-1 and version-2 primary runs.
