## 第三周：知识库、检索和评估

- 建立课程 → 文档 → 章节 → 原始段落的来源层级，并为概念卡关联证据。
- 保存原始 LaTeX、源文件行号、来源快照、校验值、版本、课程范围和审核状态。
- 已有 130 个章节节点、221 个段落、216 张概念卡，以及 SQLite 和 JSONL 导出。
- 把概念卡和长段落整理成 476 条共同嵌入输入；BGE-base-en-v1.5 生成 476 个 768 维向量，Qwen3-Embedding-0.6B 生成 476 个 1024 维向量。
- 保存精确模型版本、输入映射与校验记录；这些是调用现有嵌入模型的真实结果，没有训练新模型。
- 先有本地原生 PostgreSQL 尝试，后迁移到 Docker PostgreSQL 17 + pgvector。文档指定 Docker 为现用部署，旧原生实例已停止。
- 部署验证报告为 passed：表记录数、向量维度、索引及两套向量与原导出的逐值一致性均有记录。本次没有检查容器当前运行状态。

### 检索功能

- 实现学生不指定课程也能跨两门课程搜索。
- 结合 BGE、Qwen 语义匹配与 PostgreSQL 英文全文检索，融合候选、去重，把概念命中还原到原始证据。
- 按课程范围、已知错误和上下文预算筛选，默认最多返回六段，每个文件最多两段。
- 输出文件名、章节和行号，以及可交给回答模型的上下文与提示词。
- 已有五题基础验证、样例 JSON 和样例提示词。检索模块本身没有调用回答模型，也没有 HTTP 应用 API。

### 做过的实验

- 建立并冻结 50 道英文题，每门 25 道；46 道有支持证据，4 道用于范围或缺失信息挑战。
- 比较五种配置：BGE 向量、Qwen 向量、BGE+关键词、Qwen+关键词、双模型+关键词。
- v1 数据集偏重 textbook_reference，做来源覆盖审计后归档；v2 增加 syllabus 和 context 覆盖。两版题目改变，指标不能直接作为改进前后比较。
- v2 前六段完整证据覆盖：BGE 向量 38/46（82.6%）；Qwen 向量 41/46（89.1%）；BGE+关键词 41/46（89.1%）；Qwen+关键词 40/46（87.0%）；双模型+关键词 40/46（87.0%）。复杂组合没有自动胜过简单方案。
- 当前双模型组合在 46 道可回答题中，前三条结果的课程命中全部通过；本批记录没有范围/已知错误泄漏或来源完整性失败。
- 对六道证据不完整的题做失败诊断：遗漏证据已进入候选，但每文件两段的限制阻碍了最后选入。
- 后续诊断实验只将每文件上限从 2 改为 4：完整证据从 40/46 提升到 44/46（95.7%），必要证据组召回率从 92.0% 升到 97.3%；四题恢复，没有题退步。此实验在看过失败后设计，并非独立新题验证；生产默认仍为 2。

### 已识别的问题

- 六份来源均标为 unverified：AI 整理的课程材料不能当成完整原教材或经核实的课堂记录。
- Calculus II 内容默认排除；数论第二学期内容等待范围确认。
- 标出一处数论材料错误：Q(ζ₇) 中 2 的分解数量有疑点，默认检索排除涉及该问题的段落。
- 材料没有对应信息时，检索仍会返回相关段落；尚未建立经过验证的证据不足/拒答判断。
- 基准标签是来源锚定的 silver labels，尚未经教师确认；当前指标衡量找证据，不衡量最终回答正确性或学习效果。
