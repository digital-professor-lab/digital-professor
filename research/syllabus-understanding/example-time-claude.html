The Prompt I Used

Course Design Prompt (Syllabus → Full Breakdown)

The same structured prompt was used for every course and every model — only the bold context values changed. It is reproduced here verbatim.

You are an expert instructional designer and curriculum architect with expertise in Time Series Analysis. I will give you a syllabus and want you to reverse-engineer it into a full course design package, ending in compilable LaTeX.

Context
  • Course level: intermediate
  • Duration: 12-weeks
  • Delivery format: lecture
Find the syllabus attached to this prompt.

Produce the following, in order:

  1. Course structure — Break the syllabus into units/modules mapped to weeks or sessions. For each module: title, one-sentence goal, and the chapters/topics it covers.
  2. Topic breakdown — For every topic/chapter, list:
    • Core concepts (bulleted)
    • Learning objectives as measurable outcomes using Bloom's-taxonomy verbs (explain, derive, apply, evaluate, design, etc.)
  3. Prerequisite map — For each topic, list the specific prior concepts a student must already know, and where those are taught (earlier in this course, or assumed background). Present as a dependency table: Topic | Prerequisite(s) | Where taught.
  4. Difficulty analysis — Flag topics that are historically hard. For each:
    • Why it's hard (common misconception, abstraction jump, notational overload, missing prerequisite, cognitive load, etc.) — be specific, not generic
    • A concrete mitigation (analogy, worked-example sequencing, scaffolding steps, common-error walkthrough)
  5. Assessment plan — For each module, recommend the assessment type (low-stakes quiz, homework set, in-class exercise, midterm, project, final exam) and when in the timeline, with a one-line rationale tied to what that assessment is meant to catch (e.g., "quiz right after Module 3 to surface the recursion misconception before it compounds").
  6. Example questions — For each major topic, write 2–3 example questions spanning at least two difficulty levels (recall vs. application/analysis). Include the answer or a short grading rubric for each.
  7. Full breakdown in LaTeX — Compile everything above into one compilable LaTeX document:
    • \documentclass{article}, packages: enumitem, longtable (or booktabs), hyperref
    • One \section per module, \subsection per topic
    • Tables (longtable) for the prerequisite map and assessment schedule
    • itemize/enumerate for objectives and example questions
    • Output ONLY the LaTeX in this step's code block — no prose mixed in
Rules
  • Do steps 1–6 in plain markdown first so I can review the reasoning before you generate LaTeX.
  • If the syllabus is missing info needed for a step, state your assumption explicitly instead of skipping it.
Scope read from the syllabus, not the book. The model noticed the syllabus's own midterm dates imply a 13-teaching-week term plus a spring-break week (not the loosely stated 12), and — because the syllabus calls ARCH/GARCH and spectral methods "other topics as time allows" — it demoted them to ungraded enrichment rather than examined material. That is scope fidelity a table of contents could never provide.

Time Series Analysis (EN.553.439/639) — Full Course Design Package

Claude (Pro) · Syllabus method · Spring 2026 · based on Cryer & Chan, Time Series Analysis with Applications in R, 2nd ed.

1 · Four-Module Structure

ModuleWeeksFocus
1 · Foundations1–5 (Midterm 1, Wk 5)Description, stationarity, trends, and linear ARMA models — characterize a series and represent it as a stationary process.
2 · The Box–Jenkins Loop6–9 (Midterm 2, Wk 9)Nonstationarity, identification, estimation, diagnostics — the full difference → identify → estimate → diagnose cycle on real data.
3 · Forecasting & Seasonality10–13 (Midterm 3, Wk 13)Forecasting, seasonal SARIMA models, and time-series regression / intervention analysis.
4 · Advanced (Enrichment)14 (ungraded)ARCH/GARCH volatility and spectral/nonlinear methods — the syllabus's "as time allows" topics, treated as ungraded enrichment.

2 · A Fully Expanded Topic (Topic 4 · AR, MA & ARMA Models)

Each of the 13 topics is expanded into concepts, objectives, a difficulty note, and worked questions. One is shown in full.

Core Concepts
  • General linear process $Y_t = \sum_j \psi_j e_{t-j}$; backshift operator $B$ and operator polynomials $\phi(B),\theta(B)$
  • AR($p$), MA($q$), ARMA($p,q$) definitions
  • Stationarity (roots of $\phi(z)=0$ outside the unit circle) and invertibility conditions
  • Theoretical ACF and PACF shapes for AR/MA/ARMA processes
Learning Objectives
  1. Express an AR/MA/ARMA process in backshift-operator notation.
  2. Derive the stationarity condition for an AR($p$) process from its characteristic polynomial.
  3. Derive the theoretical ACF of an AR(1)/AR(2) or MA(1)/MA(2) process.
  4. Evaluate whether estimated coefficients yield a stationary, invertible model.
Why this topic is historically difficult. This is the first place students must connect a difference equation to a polynomial-root condition, treating $B$ as an algebraic object rather than a time-shift; $\phi(B)$ and the characteristic equation $\phi(z)=0$ look alike and get conflated.
Mitigation. Hand-iterate an AR(1) recursion numerically for $\phi=0.5$ and $\phi=1.5$ so students watch one path settle and one explode before the root condition is introduced as "the algebra that predicts what you just saw."
Example Questions
Recall Write the AR(2) model in backshift-operator form and state its characteristic equation.Answer: $(1-\phi_1 B-\phi_2 B^2)Y_t = e_t$; characteristic equation $1-\phi_1 z-\phi_2 z^2 = 0$.
Application / Analysis For $Y_t = \phi Y_{t-1} + e_t$, find the range of $\phi$ for stationarity and compute $\rho_k$.Answer: stationary for $|\phi|<1$; $\rho_k = \phi^{|k|}$.
