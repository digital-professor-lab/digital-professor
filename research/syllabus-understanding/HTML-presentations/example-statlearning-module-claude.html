2 · Key Definitions (stated verbatim in lecture)

Bayes' theorem (generative route)$p_k(x) = \dfrac{\pi_k f_k(x)}{\sum_{\ell=1}^K \pi_\ell f_\ell(x)}$, where $\pi_k=\Pr(Y=k)$ is the class prior and $f_k(x)$ the class-conditional density. The Bayes classifier $C^*(x)=\arg\max_k p_k(x)$ is unchanged from Part 1 — only how we estimate $p_k(x)$ changes.
LDA generative assumption & discriminant$X\mid Y=k \sim N(\mu_k,\Sigma)$ (shared covariance). $\delta_k(x) = x^\top\Sigma^{-1}\mu_k - \tfrac12\mu_k^\top\Sigma^{-1}\mu_k + \log\pi_k$; assign $x$ to the class with the largest $\delta_k(x)$. It is not a probability — it only ranks classes.

3 · Question Bank (samples, with solutions)

Medium For $K=2$ with common covariance $\Sigma$, show that the LDA decision boundary is linear in $x$.Solution sketch: set $\delta_1(x)=\delta_2(x)$; the quadratic $x^\top\Sigma^{-1}x$ terms cancel under a shared $\Sigma$, leaving a linear equation in $x$.
Easy/Medium A colleague argues "QDA should always be preferred, since it includes LDA as a special case." Evaluate.Solution: QDA has lower bias but far more covariance parameters ($K$ separate $\Sigma_k$), so higher variance; with small $n$ or similar class covariances, LDA generalizes better. "Includes as a special case" ≠ "always better."
