# Historical results

These records come from the real DeepSeek run on 2026-10-29. They are kept as a record of that run, and they do not match the current schemas: they predate the bundle `course_id` / `question_id` fields and use plan format @1.

Current example records are in [`../fixtures/`](../fixtures/). To create new real-model records, run `scripts/demo_turn.py` as described in the README.
